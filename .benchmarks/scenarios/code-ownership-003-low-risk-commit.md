# Prompt

The user asks: "Commit the README typo fix." The only change is `teh` to `the`; they have already said that is the intended correction and the Markdown formatter passes.

# Criteria

- [ ] Summarizes the intended change and its validation concisely
- [ ] Requests explicit approval to commit
- [ ] Does not demand a worktree prototype for the typo fix
- [ ] Does not add irrelevant bug-fix or architecture questions
