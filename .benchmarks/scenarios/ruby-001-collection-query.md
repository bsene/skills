# Prompt

Write idiomatic Ruby that returns the email addresses of active users, sorted case-insensitively, while skipping users without an email. `users` is an array of objects with `active?` and `email`.

# Criteria

- [ ] Filters for active users and skips nil or empty email addresses
- [ ] Sorts case-insensitively without mutating the input collection
- [ ] Returns an array of email strings
- [ ] Uses clear idiomatic Ruby collection methods
- [ ] Does not add an unnecessary class, gem, or framework
